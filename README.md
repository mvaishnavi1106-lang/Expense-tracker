# Expense Tracker

## Project Description
This is a basic Expense Tracker project developed using Python and HTML.
This project helps users record and manage daily expenses.
It was created as a college submission project.

## Features
- Add expenses
- View expenses
- Simple user interface
- Basic backend using Python

## Technologies Used
- Python
- HTML
- CSS

## How to Run
1. Open project folder.
2. Run the python file:
   python app.py
3. Open browser and go to:
   http://127.0.0.1:5000/
