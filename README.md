# 💰 Expense Tracker

## 📌 Project Overview

Expense Tracker is a simple web-based application designed to help users record, organize, and monitor their daily expenses. The application provides an easy way to enter expense details and keep track of spending through a clean and user-friendly interface.

The project is developed using **Python Flask** for the backend and **HTML and CSS** for the frontend.

## ✨ Features

* 💰 Add and record expenses
* 📝 Enter expense details
* 📊 View recorded expenses
* 📅 Organize expenses by date
* 💵 Track daily spending
* 🎨 Simple and user-friendly interface
* 🌐 Flask-based web application

## 🛠️ Technologies Used

* **Python** – Backend programming
* **Flask** – Web application framework
* **HTML5** – Web page structure
* **CSS3** – User interface styling
* **Visual Studio Code** – Development environment

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/expense-tracker.git
```

### 2. Open the Project

Open the downloaded project folder in **Visual Studio Code**.

### 3. Install Flask

Open the VS Code terminal and run:

```bash
python -m pip install flask
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

Open the following address in your browser:

```text
http://127.0.0.1:5000/
```
